# Day 15: Coffee Machine

A coffee machine you control by typing in the terminal.

- Type `espresso`, `latte` or `cappuccino` to order a drink.
- Type `report` to see how much water, milk and coffee is left and how much money was made.
- Type `off` to turn the machine off.

When you order, the machine checks that it has enough ingredients, asks you for coins (quarters, dimes, nickels and pennies), gives change if needed and then makes the drink. If you don't pay enough, you get your money back.

You need Python 3.12 or newer for this one.

To run it: `python main.py`
