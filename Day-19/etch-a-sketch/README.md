# Day 19: Etch A Sketch

A small drawing program made with `turtle`. You move the turtle with the keyboard and it draws a line behind it.

| Key | What it does |
|---|---|
| W / S | move forward / backward |
| A / D | turn left / right |
| C | clear the drawing and go back to the start |

Click the window to close it.

To run it: `python main.py`
