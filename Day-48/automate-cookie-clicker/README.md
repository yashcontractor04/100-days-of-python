# Day 48: Cookie Clicker Bot

Automates playing Cookie Clicker using Selenium[span_0](start_span)[span_0](end_span). It clicks the big cookie continuously and buys the most expensive store item you can afford every 5 seconds. When the 5-minute run finishes, it writes your game progress to `save.txt` and reloads it automatically on the next run.

You don't need any API keys for this.

To run it: `python main.py`
