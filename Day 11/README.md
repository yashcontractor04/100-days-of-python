# Blackjack Capstone Project
A CLI implementation of the classic Blackjack (21) card game with standard dealer rules, dynamic Ace valuation, and natural Blackjack detection.

### Tech / Concepts
* Python 3
* Dynamic rule evaluation (soft vs. hard Ace adjustment)
* Automated dealer decision logic (`hit` until $\ge 17$)

### Quickstart
`python main.py`
