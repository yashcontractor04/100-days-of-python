# Day 45: Top 100 Movies Web Scraper

Scrapes an archived Empire Magazine page of the 100 greatest movies of all time using BeautifulSoup. It reads the movie titles from the page, reverses the list so it starts at number 1 (The Godfather) instead of 100, and saves them to a file called `movies.txt`.

You don't need any API keys for this.

To run it: `python main.py`
