# Day 11: Blackjack

Play Blackjack (also called 21) against the computer.

The rules in this version:

- An Ace is worth 11, but it counts as 1 if you would go over 21.
- Getting 21 with your first two cards is a Blackjack.
- The computer keeps drawing cards until it has 17 or more.
- You only see the computer's first card until the round is over.

Cards are picked at random from a list every time, like an endless deck. There are no suits and it doesn't remember which cards were already dealt.

To run it: `python main.py`
