# Day 17: Quiz Game

A true/false quiz in the terminal, built with classes.

- `Question` stores one question and its answer.
- `QuizBrain` keeps track of which question you are on, checks your answer and keeps the score.
- `data.py` has the list of questions.

The questions are in the same format that the Open Trivia Database website uses. I use that website for real in Day 34.

To run it: `python main.py`
